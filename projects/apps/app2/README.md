# React + TypeScript + ActionStack

A React demo that shows Actionstack working outside Angular. The application is
built with the Angular CLI's esbuild-based `application` builder, so it uses the
same workspace tooling as the Angular app.

## Development

From the repository root:

```bash
npm run react:serve
```

## Build

From the repository root:

```bash
npm run react:build
```

The output is written to `dist/app2/browser`.
